что внутри

Всё, что обычно делает облако - только не в облаке

Захват, расшифровка, разбор по спикерам, саммари и поиск по истории встреч - каждый этап выполняется локально, теми же движками, что стоят за большими сервисами, только без сети.

01

Запись без бота

Никто не видит участника «LoMeet Notetaker» в списке звонящих - потому что его там нет. Звук пишется прямо с устройства через ffmpeg, мимо API площадки видеосвязи.

02

Расшифровка на месте

faster-whisper распознаёт речь прямо на Mac. Аудиофайл никогда не покидает диск - его не нужно никуда загружать, чтобы получить текст.

03

Кто говорит

Разбор по спикерам - тоже локально, sherpa-onnx, без аккаунта и токена доступа. Просто работает после первого запуска.

04

Саммари локальной моделью

Ollama строит саммари прямо на устройстве - без ключа OpenAI, без счёта за токены, без отправки транскрипта куда-либо.

05

Выбор источника

Экран, конкретное окно или только звук.

06

Умный поиск

Чат по всей истории встреч с переходом к нужному моменту записи по клику - см. следующий раздел.

Разница - не в списке функций, а в том, куда уходит звук

Большинство сервисов записи встреч устроены одинаково: бот-участник заходит в звонок, а обработка - расшифровка, саммари - происходит на серверах вендора. LoMeet устроен иначе на уровне архитектуры.

Что происходит LoMeet Типичный облачный бот
Кто виден в списке участников никто бот-участник
Куда уходит звук остаётся на устройстве на сервер вендора
Где расшифровка и саммари локально, на Mac в облаке
Нужен аккаунт нет да
Работает офлайн да, после установки моделей нет
Стоимость бесплатно подписка

Сравнение по архитектуре, не по конкретному вендору. У части сервисов есть и «безботовый» локальный захват звука - но обработка почти всегда всё равно уходит в облако для расшифровки.

умный поиск

Задайте вопрос всей истории встреч - не одной записи

«Что мы решили по срокам в июле?» - LoMeet ищет ответ по транскриптам и саммари всех прошлых встреч и указывает, из какой именно записи и с какого момента взят ответ. Клик по источнику - и плеер сразу перематывает к нужной секунде.

под капотом

Настоящий стек, не обёртка вокруг чужого API

LoMeet не проксирует запросы к внешним LLM-сервисам. Каждый компонент - отдельный локальный процесс, который можно проверить и остановить в любой момент.
